```bash
npm install --prefix "$PI_RESEARCH_AGENT_DIR/npm" --no-save --package-lock=false --legacy-peer-deps @ricoyudog/pi-goal-hermes@0.1.0
```

在该agent的 `settings.json` 中显式通过 `packages` 注册原生包，按需加载。

应用入口：`scripts/apply-goal-hermes-patch.mjs`。
脚本仅处理操作者显式给出的隔离 `agent/npm/node_modules` 中目标包。
脚本仅应用已安装包，不代为安装或选择个人agent目录。
脚本核对版本与9文件原始／目标hash，拒绝未知版本、未知源码或混合状态。

```bash
node scripts/apply-goal-hermes-patch.mjs "$PI_RESEARCH_AGENT_DIR" --dry-run
node scripts/apply-goal-hermes-patch.mjs "$PI_RESEARCH_AGENT_DIR" --apply
node scripts/apply-goal-hermes-patch.mjs "$PI_RESEARCH_AGENT_DIR" --check-only
```

给定目标目录但省略模式参数时，默认 `--dry-run`。
