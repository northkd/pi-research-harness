## 整合时修复的交叉问题

1. **暂停与队列操作**：保留 main 的 pause/resume；暂停状态参与队列 revision，前端显示暂停并禁止立即启动。排序或提高并发数不能悄悄恢复暂停计划。
2. **任务元数据边界**：工具、后端与共享来源校验统一接受 1–64 项真实任务；保留任期字段，修复共享提示构造中未定义的错误函数。
3. **完成与恢复的共享席位**：直接子会话与计划子会话的完成回执接入共享准入；等待异步持久释放成功，才对外声明释放。无已结算 assignment 的直接协作子会话再次继续执行时，必须重新验证当前任期、成员、资源和容量。
4. **历史／移出结果归档**：保留原任务的结果归档身份，但不授权旧主向下派发，也不唤醒已移出的父会话。已验证结果的 exact-token 清理不依赖旧父继续接入。
5. **旧来源容量计数**：全量回归发现旧会话缺少 spawnToken 时被首次准入误排除，已修正为仅排除明确存在的当前 token。保留拒绝前没有 prepare/spawn 副作用的断言，并覆盖同父与跨父旧来源。
6. **已结算任务不隐式重开**：额外复现了已结算 assignment 被消息恢复后，重启时旧回执再次释放席位的问题。此版本不声称支持任务重开协议；向已结算 assignment 发送继续工作的请求、回复或决策会明确拒绝，并指导创建新的补充计划／任务。未投递的旧恢复通知也不会在重启后绕过该规则；原结果与新工作分账保留。
